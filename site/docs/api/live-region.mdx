---
title: Tree.LiveRegion
description: The tree's polite live region. It shows the text your announce function returns for each drag step or failed load, and writes none of its own.
---

`Tree.LiveRegion` is a `role="status"`, `aria-live="polite"` element showing the latest text the
root's `announce` returned. The package writes no text: without `announce`, it stays empty. The
WAI-ARIA APG asks a drag and drop to be perceivable without sight; this is where your words go.
Hide it visually with your own class.

<Framework name="react">

```tsx
<Tree.Root<Types> defaultTree={json} announce={announce} aria-label="Files">
    <Tree.Items<Types>>{(item) => <FileItem item={item} />}</Tree.Items>
    <Tree.LiveRegion className="visually-hidden" />
</Tree.Root>
```

</Framework>

<Framework name="vue">

```vue
<Tree.Root :default-tree="json" :announce="announce" aria-label="Files">
    <Tree.Items v-slot="{ item }"><FileItem :item="item" /></Tree.Items>
    <Tree.LiveRegion class="visually-hidden" />
</Tree.Root>
```

</Framework>

<Framework name="angular">

```html
<div treeRoot [defaultTree]="json" [announce]="announce" aria-label="Files">
    <ng-template [treeItems]="json" let-item>
        <div [treeItem]="item">
            <div treeItemContent>{{ item.label }}</div>
            <div treeGroup></div>
        </div>
    </ng-template>
    <div treeLiveRegion class="visually-hidden"></div>
</div>
```

</Framework>

`announce` receives an `AnnounceEvent` and returns a string, or `undefined` to say nothing:

| event | fields | when |
| --- | --- | --- |
| `drag-start` | `itemIds`, `keyboard` | a drag starts (pointer, or keyboard when `keyboard` is true) |
| `drag-over` | `itemIds`, `target` (`DropTarget \| null`) | the drop target changes; `null` when there is no valid one |
| `drop` | `itemIds`, `target` | the items were dropped (one `item.move`) |
| `drag-cancel` | `itemIds` | the drag was cancelled |
| `load-error` | `itemId`, `error` | a load of an item's children failed |

The latest text is also `engine.get("announcement")`. See
[Drag and drop](/docs/guides/drag-and-drop#announcing-the-drag).

## Props

`LiveRegionProps` has no props of its own: it takes the
[common primitive props](/docs/api/root#common-props) (on a `div`), with `LiveRegionState`.

## State

`LiveRegionState`:

| field | type | description |
| --- | --- | --- |
| `announcement` | `string` | the latest text `announce` returned (`""` before any) |

## Attributes

| attribute | when |
| --- | --- |
| `role="status"` | always |
| `aria-live="polite"` | always |
| `aria-atomic` | always |
| `data-tree-part="live-region"` | always |
