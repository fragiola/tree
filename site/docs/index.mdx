<Features columns={4}>
<Feature title="Behaviour">
Expand and collapse, single and multiple selection, tri-state checkboxes, inline rename, Pointer
Events drag and drop with a keyboard drag, and children loaded on demand.
</Feature>
<Feature title="Accessibility">
The WAI-ARIA APG tree view: roles, levels, positions, the roving tab stop, type-ahead and a live
region whose words are yours.
</Feature>
<Feature title="A typed JSON model">
The tree is data, typed by your registry: load it, save it, and veto or rewrite every command
with middleware, from a click or from an assistant.
</Feature>
<Feature title="Primitives">
Root, Items, Item, ItemContent, Group, Toggle, Checkbox… each renders only what you give it, with
render instead of asChild. You own the recursion.
</Feature>
</Features>

<Section title="What it never ships">
<Pills strike items={["CSS", "Icons", "Text", "Rendered menus", "A design system"]} />

The state is exposed as data-\* attributes and ARIA, so any styling solution works: Tailwind,
plain CSS, CSS modules, CSS-in-JS. The examples use Fragiola UI and its palettes.
</Section>
