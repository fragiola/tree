---
title: Composition
description: You own the recursion. The primitives hand you items through children functions, and your item component decides what each row and group renders.
---

Most tree components take a data structure and render it for you, with a slot or two to
customize. Here **you write the recursion**: `Tree.Items` calls your function with each root
item, and `Tree.Group`, inside your item, calls it with each child (in Angular, one
`<ng-template treeItems>` that `treeGroup` renders again). Whatever your item component
renders, the primitives give it the roles, the state and the behaviour.

## The shape of an item

<Framework name="react">

```tsx
import { type ItemOf, Tree } from "@fragiola/tree-react";

function Node({ item }: { item: ItemOf<Types> }) {
    return (
        <Tree.Item item={item}>
            {/* the row: what is pressed, selected and dragged */}
            <Tree.ItemContent>
                <Tree.Toggle>▸</Tree.Toggle>
                {item.label}
            </Tree.ItemContent>
            {/* the children, rendered by this same component */}
            <Tree.Group<Types>>{(child) => <Node item={child} />}</Tree.Group>
        </Tree.Item>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="node.vue"
<script setup lang="ts">
import type { ItemOf } from "@fragiola/tree-vue";
import { Tree, type Types } from "./tree"; // Tree = typedTree<Types>()

defineProps<{ item: ItemOf<Types> }>();
</script>

<template>
    <Tree.Item :item="item">
        <!-- the row: what is pressed, selected and dragged -->
        <Tree.ItemContent>
            <Tree.Toggle>▸</Tree.Toggle>
            {{ item.label }}
        </Tree.ItemContent>
        <!-- the children, rendered by this same component -->
        <Tree.Group v-slot="{ item: child }">
            <Node :item="child" />
        </Tree.Group>
    </Tree.Item>
</template>
```

</Framework>

<Framework name="angular">

In Angular the recursion is one template: `treeItems` renders it with each root item, and a
`treeGroup` with no template of its own renders it with each child.

```html
<ng-template [treeItems]="model" let-item>
    <div [treeItem]="item">
        <!-- the row: what is pressed, selected and dragged -->
        <div treeItemContent>
            <span treeToggle>▸</span>
            {{ item.label }}
        </div>
        <!-- the children, rendered with this same template -->
        <div treeGroup></div>
    </div>
</ng-template>
```

</Framework>

- `Tree.Item` is the `role="treeitem"` element, the one DOM focus goes to. It provides the item
  to the parts inside it.
- `Tree.ItemContent` is the row: a press selects it, a drag starts from it, and the drag
  hit-tests its rectangle. Put everything the row shows inside it.
- `Tree.Group` is the `role="group"` element of the children, rendered only while the item is
  expanded.
- `Tree.Toggle` is optional, anywhere inside the item.
- A check control and a label editor are yours: an element of your own that reads the item's
  state and runs a command (`item.toggle-check`), and an input wired by `useTreeItemRename`. See
  the [checkboxes](/docs/guides/checkboxes) and [rename](/docs/guides/rename) guides.

## Different items, different rows

Since the recursion is yours, each kind of item can render its own row, and `item.data` narrows
on `item.kind`:

<Framework name="react">

```tsx
function Node({ item }: { item: ItemOf<Types> }) {
    return (
        <Tree.Item item={item}>
            <Tree.ItemContent className="row">
                {item.kind === "folder" ? (
                    <>
                        <Tree.Toggle>▸</Tree.Toggle>
                        <FolderIcon aria-hidden />
                    </>
                ) : (
                    <FileIcon aria-hidden />
                )}
                <span>{item.label}</span>
                {item.kind === "file" && <small>{formatSize(item.data.size)}</small>}
            </Tree.ItemContent>
            <Tree.Group<Types>>{(child) => <Node item={child} />}</Tree.Group>
        </Tree.Item>
    );
}
```

</Framework>

<Framework name="vue">

```vue
<template>
    <Tree.Item :item="item">
        <Tree.ItemContent class="row">
            <template v-if="item.kind === 'folder'">
                <Tree.Toggle>▸</Tree.Toggle>
                <FolderIcon aria-hidden="true" />
            </template>
            <FileIcon v-else aria-hidden="true" />
            <span>{{ item.label }}</span>
            <small v-if="item.kind === 'file'">{{ formatSize(item.data.size) }}</small>
        </Tree.ItemContent>
        <Tree.Group v-slot="{ item: child }">
            <Node :item="child" />
        </Tree.Group>
    </Tree.Item>
</template>
```

</Framework>

<Framework name="angular">

```html
<ng-template [treeItems]="model" let-item>
    <div [treeItem]="item">
        <div treeItemContent class="row">
            @if (item.kind === "folder") {
                <span treeToggle>▸</span>
                <svg lucideFolder aria-hidden="true"></svg>
            } @else {
                <svg lucideFile aria-hidden="true"></svg>
            }
            <span>{{ item.label }}</span>
            @if (item.kind === "file") {
                <small>{{ formatSize(item.data.size) }}</small>
            }
        </div>
        <div treeGroup></div>
    </div>
</ng-template>
```

</Framework>

## Controls in a row

A button, a link or an input inside `Tree.ItemContent` keeps its own presses and keys: a press on
it neither selects the row nor starts a drag, and Enter or Space on it is the control's, not the
tree's. To exempt another element (a slider, a custom menu
trigger), give it the `data-tree-no-drag` attribute (`NO_DRAG_ATTRIBUTE`); the full list is
`DRAG_EXEMPT`.

<Framework name="react">

```tsx
<Tree.ItemContent>
    <span>{item.label}</span>
    <button type="button" aria-label={`Delete ${item.label}`} onClick={() => remove(item.id)}>
        ×
    </button>
</Tree.ItemContent>
```

</Framework>

<Framework name="vue">

```vue
<Tree.ItemContent>
    <span>{{ item.label }}</span>
    <button type="button" :aria-label="`Delete ${item.label}`" @click="remove(item.id)">×</button>
</Tree.ItemContent>
```

</Framework>

<Framework name="angular">

```html
<div treeItemContent>
    <span>{{ item.label }}</span>
    <button type="button" [attr.aria-label]="'Delete ' + item.label" (click)="remove(item.id)">×</button>
</div>
```

</Framework>

## Your own elements

<Framework name="react">

Every primitive renders a `div` (a `span` for the toggle) and takes `render` to replace it, never `asChild`. For a list markup:

```tsx
<Tree.Root<Types> defaultTree={json} aria-label="Files" render={<ul />}>
    <Tree.Items<Types>>{(item) => <Node item={item} />}</Tree.Items>
</Tree.Root>

// in Node
<Tree.Item item={item} render={<li />}>…</Tree.Item>
<Tree.Group<Types> render={<ul />}>{(child) => <Node item={child} />}</Tree.Group>
```

When a primitive is not enough, `useTreeItem(item)` gives an item's state and the props of its
element, to build one on anything ([Hooks](/docs/api/hooks)).

</Framework>

<Framework name="vue">

Every primitive renders a `div` (a `span` for the toggle) and takes `as` to replace it (a tag or a component), never `asChild`. For a list
markup:

```vue
<Tree.Root :default-tree="json" aria-label="Files" as="ul">
    <Tree.Items v-slot="{ item }"><Node :item="item" /></Tree.Items>
</Tree.Root>

<!-- in node.vue -->
<Tree.Item :item="item" as="li">…</Tree.Item>
<Tree.Group as="ul" v-slot="{ item: child }"><Node :item="child" /></Tree.Group>
```

For full control, the `render` scoped slot gives the props to bind and the state:
`<template #render="{ props, state, children }">`, then `<li v-bind="props">` with
`<component :is="children" />` inside. When a primitive is not enough, `useTreeItem(item)` gives
an item's state and the props of its element, to build one on anything
([Vue primitives](/docs/api/vue)).

</Framework>

<Framework name="angular">

A directive goes on an element you write, so the element is yours: no `render`, no `as`, never
`asChild`. For a list markup:

```html
<ul [treeRoot]="model" aria-label="Files">
    <ng-template [treeItems]="model" let-item>
        <li [treeItem]="item">
            <div treeItemContent>{{ item.label }}</div>
            <ul treeGroup></ul>
        </li>
    </ng-template>
</ul>
```

An item's state is a signal through `exportAs`: `#node="treeItem"`, then `node.state().expanded`
anywhere inside it. A component inside an item reads it with `injectTreeItem()`
([Angular primitives](/docs/api/angular)).

</Framework>

## Reaching the tree from inside

<Framework name="react">

Any component inside `Tree.Root` reads the model and the engine with `useTree<Types>()`, and a
value of the state with `useTreeState`:

```tsx
function SelectionCount() {
    // the selection feature's field: pass the features with the registry
    const count = useTreeState<Types, number, typeof features>(
        (state) => state.selectedItemIds.length,
    );
    return <p>{count} selected</p>;
}
```

From outside the root (a toolbar beside it), use a tree ref: `useTreeRef<Types>()`, passed as
the root's `treeRef`.

</Framework>

<Framework name="vue">

Any component inside `Tree.Root` reads the model and the engine with `useTree<Types>()`, and a
value of the state with `useTreeState`, a read-only ref:

```vue
<script setup lang="ts">
import { useTreeState } from "@fragiola/tree-vue";

const count = useTreeState<Types, number, typeof features>(
    (state) => state.selectedItemIds.length,
);
</script>

<template>
    <p>{{ count }} selected</p>
</template>
```

From outside the root (a toolbar beside it), use a tree ref: `useTreeRef<Types>()`, passed as
`:tree-ref="tree"` and read as `tree.value`, in the template as in the script:

```vue
<script setup lang="ts">
import { useTreeRef } from "@fragiola/tree-vue";

const tree = useTreeRef<Types>();
</script>

<template>
    <button type="button" :disabled="!tree.value" @click="tree.value?.model.run('tree.collapse-all', {})">
        Collapse all
    </button>
    <Tree.Root :tree-ref="tree" :default-tree="json" aria-label="Files">…</Tree.Root>
</template>
```

</Framework>

<Framework name="angular">

Any component inside `[treeRoot]` reads the model and the engine with `injectTree<Types>()`, and
a value of the state with `injectTreeState`, a signal:

```ts
@Component({
    selector: "app-selection-count",
    template: `<p>{{ count() }} selected</p>`,
})
export class SelectionCount {
    protected readonly count = injectTreeState<Types, number, typeof features>(
        (state) => state.selectedItemIds.length,
    );
}
```

From outside the root (a toolbar beside it), use a template reference: `#tree="treeRoot"` gives
its `model()` and its `engine` to the rest of the template, and `viewChild(TreeRootDirective)` to
the component's class.

</Framework>
