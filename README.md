# Fragiola Tree

A headless, accessible tree view for React, Vue and Angular: expand and collapse, selection,
the WAI-ARIA keyboard model, drag and drop, async children, inline rename and tri-state
checkboxes. It ships behaviour, accessibility and composable primitives, and no CSS, icons or
text. You bring the styling.

Part of [Fragiola](https://fragiola.com). Documentation: <https://fragiola.com/tree>.
