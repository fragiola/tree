The first release of `@fragiola/tree`, the framework-free core of Fragiola Tree: the tree model
(a versioned JSON document and its JSON Schema, 27 commands with JSON Schemas, `get`/`is` queries,
middleware, events, `batch`, `dispatch`) and the engine (DOM focus, the WAI-ARIA keyboard model
with type-ahead, Pointer Events drag and drop with a keyboard drag, async children loading,
announcements). Expand and collapse, single and multiple selection, inline rename and tri-state
checkboxes.
